# TripMate — Travel Planner
**Domain:** Travel & Tourism | **Stack:** Flutter, Dart, Material 3

Features:
- Travel plan cards with destination, trip length, budget and travel style
- Create a trip using validated form fields
- Adjustable trip length and travel-style selection
- Responsive cards and gradient hero section

Run:
```bash
flutter pub get
flutter run
```
Demo only: trip data is in memory and does not fetch live travel prices or create a real itinerary.

Resume description (after testing):
- Built a Flutter/Dart travel planning UI to organize destination ideas, budgets, trip length and travel preferences.
- Implemented validated trip creation and reusable trip cards.
